# InVision Studio AI 🚀
### الجيل الجديد من استوديو التصميم المتجه المدعوم بوكلاء الذكاء الاصطناعي (DeepSeek)

تم بناء وتطوير هذا المشروع في مجلد `C:\InVision Studio` استناداً إلى وثيقة **التحليل الوظيفي لـ InVision** مع إضافة **اللمسة الذكية الثورية: منظومة وكلاء الذكاء الاصطناعي متعددة الأدوار بقيادة محرك ديب سيك (DeepSeek)**.

---

## 🌟 الميزات الرئيسية واللمسة الجديدة

### 1. مركز وكلاء ديب سيك (DeepSeek Multi-Agent Hub) 🤖
* **وكيل معمار الواجهات (DeepSeek Canvas Architect):**
  - فهم متطلبات واجهات المستخدم باللغة العربية والإنجليزية.
  - توليد كائنات متجهة حقيقية (شاشات تسجيل دخول، بطاقات إحصاءات KPI، بطاقات ميزات، أشرطة تنقل) وحقنها مباشرة في شجرة المشهد (Scene Graph).
* **وكيل نظم التصميم (DeepSeek Design Tokens):**
  - صياغة لوحات ألوان دلالية متناسقة، ومقاييس الخطوط وهوامش الفراغات.
* **وكيل تسليم المطورين (DeepSeek Code Engine):**
  - فحص أي عنصر وتوليد كود إنتاجي جاهز (React JSX, Tailwind CSS, SwiftUI, Jetpack Compose).
* **مدقق الوصول والتجربة (DeepSeek UX Auditor):**
  - فحص تباين الألوان وفق معايير WCAG AAA وملاءمة أبعاد عناصر التفاعل.
* **محاكي ذكي مدمج (Smart Simulator):** يعمل المشروع فوراً بكامل طاقته حتى قبل إدخال مفتاح API الخاص، مع إمكانية إدخال مفتاح DeepSeek الحي في أي لحظة للاتصال المباشر.

### 2. محرك مساحة العمل اللانهائية (Infinite Canvas) 📐
* مساحة عمل غير محدودة مع تحويل إحداثيات متوازي (Pan & Zoom عبر العجلة والسحب).
* شجرة المشهد (Scene Graph) تدعم ترتيب الطبقات، القفل، الإخفاء، وإعادة التسمية.
* إطار تحويل كامل مع 8 مقابض تفاعلية لتغيير الحجم وإعادة التموضع.

### 3. محرك التحريك التفاعلي (Auto-Animate Engine) ⚡
* انتقال تلقائي بين الشاشات بمعدل **60 إطاراً في الثانية (60 FPS)**.
* مطابقة المعرفات المستقرة (`transitionKey` مثل `btn_submit`) واشتقاق فروق الموضع والحجم تلقائياً.
* تحكم مرن في منحنيات الاستيفاء (`cubic-bezier(0.4, 0.0, 0.2, 1)`) وسرعة الانتقال.

### 4. التفتيش البرمجي ونظم التصميم (Developer Handoff & Tokens) 💻
* مخطط الصندوق البصري (Box Model: Margin, Border, Padding, Width × Height).
* تصدير فوري للأكواد ورموز التصميم بصيغة JSON ومتغيرات CSS.

## 🚀 التشغيل والتطوير

الخادم يعمل حالياً على:
```
http://localhost:3000
```

لإعادة التشغيل مستقبلاً:
```bash
# تثبيت الحزم (إن لم تكن مثبتة)
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build
```
